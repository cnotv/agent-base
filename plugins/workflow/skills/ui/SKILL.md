# UI

Interface text is read at a glance. Keep controls short and move explanation out of the way.

## Checkboxes

- **A checkbox label is at most 12 characters.** "Auto apply", not "Auto apply the code to the
  editor".
- Longer explanation goes in a tooltip on the label or in a collapsed section, never beside the
  control.
- Go past 12 only when no shorter word keeps the meaning, and say so in the pull request.
