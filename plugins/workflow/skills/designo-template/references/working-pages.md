# Working page skeletons

Fill every bracket from the intake. Each working page carries the label `WORKING PAGE · <NAME> · NOT PART OF THE PRODUCT` at the top and the footer `<Title> · illustration template · page n of N` at the bottom. Text is sans, 8.5 to 9.5 pt; headings use the display face.

## Cover and back cover

Cover placeholder: label `COVER ILLUSTRATION · FULL BLEED`, one sentence scene, then a layout note naming the quiet zone for the title ("leave the upper third quiet") and the bleed to paint past. Live text: title, subtitle, `[Author name] · illustrated by [Illustrator name]`.

Back cover placeholder: scene seen from a distance, a clear lower panel for the blurb and barcode. Live text: blurb, tagline, credit line, and a boxed `ISBN / barcode` zone plus `[Publisher]`. Placeholders in brackets stay until the owner supplies the real data; never invent them.

## 1. How to use this template

1. What is in the file: page count and parts, trim, bleed, safe margin, art size in points.
2. Your workflow: the painting tool, canvas size in pixels and dpi, colour profile, which area stays quiet because the scrim covers it, export as PNG not JPG, file names `Title_p01.png` to `Title_pNN.png`, drop the PNG above the placeholder then hide the group, and a check at 25 percent (the glow still reads, no face sits under text).
3. Rules: never retype, resize or recolour the live text (state family, size, weight, colour); one idea per page, a second moment becomes a small corner vignette; name the only light sources; list the bans (outlines, pure white, airbrush) and what to keep showing (paper grain).
4. Before you send it back: keep text live and art on its own layer, name layers by page, send the layered file and the PNGs, and the print check (dpi, colour conversion at export, one proof on the real paper).

## 2. Art direction

Subheads, each two or three sentences: Tone (including what must never happen, such as scary), Medium (technique plus the exact tool recipe, for example brush names and a paper grain layer at 8 to 12 percent Multiply), Light (which sources are warm, how a glow behaves, the darkest allowed value), Colour script (the sequence across pages, for example dark, light, dark, with one colour name per page), Palette (name, swatch and hex in a grid, then the four colours per spread rule and a note that hex is for the digital sketch while print is mixed to match).

## 3. Characters and continuity

One sketch box per character, labelled `NAME` and `sketch / paste reference`, above a paragraph for each: age or kind, colouring, clothing or markings, scale against another character, emotional arc. Say the look is a suggestion until the owner confirms it. Finish with Props and continuity: each recurring object with its look and the pages it appears on, and any fixed side rule ("the calf stays on the left").

## 4. Map

A table with columns page, chapter, scene, colour, plus shot type where useful. One row per content page. One sentence above it states the arc and the rule that the glow is the lightest value on each page.

## 5. Preflight

Pass or fail list with the date: art in, text unchanged, longest page verified in the PDF, page count multiple of 4, colour space, dpi, bleed, safe margin, placeholders hidden, working pages removed from the print export. End with the plain statement of what still blocks print.
